Trình Tạo Bài Thi Hợp Nhất — Môn Toán

1 Luồng duy nhất: Tải File Đề Ôn → Chọn đáp án trực tiếp trên UI hoặc tải File Đáp Án Đúng → Lưu & Thi ngay

Bước 1: Tải lên File Đề Ôn (Cấu trúc mới THPTQG 2025) Hỗ trợ .docx, .doc, .pdf, .txt, .rtf
Bước 2: Thiết Lập Đáp Án Đúng & Lời Giải (Hỗ trợ cả 3 phần) Sẵn sàng gán đáp án
Tùy chọn 1: Chỉnh đáp án trực tiếp trên UI xem trước

• Phần I: Click A, B, C, D.
• Phần II: Bấm nút [Đúng] hoặc [Sai] cho từng ý a, b, c, d.
• Phần III: Nhập đáp số chuẩn (chấp nhận cả dấu phẩy , và dấu chấm .).

Tùy chọn 2: Tải lên File Đáp Án Đúng riêng biệt

Tự động khớp theo số câu và cấu trúc: 1.A, 2.B (Phần I), 1: a-Đ, b-S, c-Đ, d-Đ hoặc Đ-S-Đ-Đ (Phần II), và số/văn bản (Phần III) kèm lời giải chi tiết cho Anh Ba.
